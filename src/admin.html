    Em uso

    O modelo que os usuários recebem como padrão.

    Conexão

    Cole a URL da API e o token. O KIRA reconhece o provedor sozinho.

    Atalhos

    Qualquer API no formato da Anthropic ou da OpenAI funciona. Em branco, o KIRA tenta reconhecer pelo token.

    Fica guardado só no servidor e nunca é mostrado aos usuários.

    Avançado

    Use só se o reconhecimento automático errar, por exemplo num gateway próprio.

    Origem do modelo gratuito

    O que os usuários usam ao escolher "KIRA Free".

    Nemotron 3 Super 120B, incluído na conta da Cloudflare: 10.000 neurons grátis por dia (cerca de 30 a 50 mensagens).

    Crie em openrouter.ai/settings/keys ↗. Fica guardada só no servidor.

    Modelos terminados em :free não custam nada: 20 por minuto e 50 mensagens por dia na conta toda (1.000 por dia depois de comprar US$ 10 em créditos). Nesses modelos, a OpenRouter e o provedor podem guardar os textos enviados.

    Instruções para o modelo

    Enviadas em todas as conversas, nas duas opções de IA. Use para definir tom, público, formato das respostas ou informações do seu negócio.

    0 / 8.000
    Exemplos

    As instruções entram depois do prompt padrão da KIRA. As regras de uso responsável do prompt padrão continuam valendo, e o modelo segue as suas instruções desde que não as contrariem.

    Supabase

    Com o login ativo, só quem tem conta usa o KIRA. As contas ficam no seu projeto da Supabase.

    Na Supabase: Project Settings → API Keys. Use a chave pública, nunca a secreta (sb_secret_ ou service_role).
